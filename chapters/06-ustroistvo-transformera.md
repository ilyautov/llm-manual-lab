## 6 Устройство трансформера

<!-- e:77 override -->
Трансформер многократно обновляет представления токенов через attention и FFN — полносвязную сеть внутри блока. Остаточные связи передают сигнал между слоями, нормализация помогает устойчивости вычислений. Исходная архитектура Vaswani и соавторов включала encoder и decoder [3]. Многие генеративные LLM используют только decoder.

<!-- e:78 -->
Attention даёт каждой позиции способ получить информацию из других доступных позиций. Для этого из представлений вычисляют три набора векторов: Q — queries, K — keys, V — values. Удобная аналогия: query задаёт, какую связь ищем; key участвует в оценке соответствия; value содержит информацию, которую передаём. Это объяснение роли операций, а не буквальное описание сознательного поиска.

<!-- e:79 формула -->
```text
Attention(Q, K, V) = softmax(QKTdk + M)V
```

<!-- e:80 -->
Матрица QKᵀ содержит оценки совместимости позиций. Здесь dₖ — размерность query и key. Деление на её квадратный корень помогает контролировать масштаб. В аддитивной маске M разрешённым связям соответствует 0, запрещённым — минус бесконечность. Softmax применяется по доступным ключам для каждой query и превращает оценки в веса. Умножение на V собирает взвешенную смесь информации [3].

<!-- e:81 -->
В multi-head attention несколько наборов проекций выполняют такую работу параллельно. Разные головы могут использовать разные зависимости. Их результаты объединяются. Нельзя заранее назначить всем головам фиксированные человеческие функции вроде «эта отвечает за сарказм».

<!-- e:82 override -->
Далее полносвязная сеть FFN (feed-forward network) преобразует представление каждой позиции. Она использует одни и те же параметры для позиций внутри слоя. В MoE (mixture of experts, смесь экспертов) часть этих преобразований выполняют выбираемые сети-эксперты; механизм подробно разобран в главе 15.

<!-- e:83 -->
Порядок токенов тоже должен попасть в вычисления. Есть разные позиционные механизмы. RoPE, например, поворачивает компоненты query и key в зависимости от позиции, позволяя учитывать относительное расположение [5]. Современные семейства могут использовать нормализацию, gated activations и другие изменения; техническая статья LLaMA даёт конкретный пример такой архитектуры [4].

<!-- e:84 -->
При полном attention число пар позиций растёт квадратично с длиной последовательности. Это относится к данной операции, а не означает, что вся стоимость любого инференса всегда ровно квадратична. Есть ограниченное внимание, специальные кеши и другие способы организации вычислений.

<!-- e:85 -->
Для лаборатории. Карта attention показывает часть вычисления, но не заменяет объяснение причины ответа. Для проверки результата полезнее реальные тесты и источники.
