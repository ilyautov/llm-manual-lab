# Как участвовать

Книга и лаборатория принимают замечания и правки. Одно изменение на один pull request: так рецензия проходит быстро, а автор замечания попадает в CHANGELOG.

## Что можно сообщать

- **Ошибка в книге**: опечатка, неверное число, неточный факт. Откройте issue по шаблону «Ошибка в книге» с номером страницы и цитатой.
- **Ошибка в лаборатории**: команда падает, тест не проходит, число расходится с текстом. Шаблон «Ошибка в лаборатории», приложите вывод целиком.

## Как устроена книга

Текст книги живёт в `manual/source.docx` с редакторскими правками в `manual/editorial_content.py`; дополнительные разборы и дополнения собирает `manual/build_manual.py`. Редакция хранится в `manual/publication.json` и автоматически попадает на обложку, в метаданные и выходную страницу. Шрифты лежат в `manual/fonts`, книга собирается из чистого клона.

## Что считается проверкой

Перед отправкой прогоните и приложите вывод:

```bash
npm test                       # тесты лаборатории
python manual/build_manual.py  # сборка PDF (нужен Python 3 и requirements.txt)
python scripts/check_pdf.py    # регрессионная проверка содержимого PDF
```

Правки по индексам элементов DOCX хрупки: после любой вставки пересобирайте PDF и запускайте check_pdf.

## Чего мы не делаем

- Не добавляем внешние npm-зависимости: тесты лаборатории работают на чистом Node.js 24 без сети.
- Не выкладываем данные живой лаборатории наружу: локальный Ollama остаётся локальным.
- Не вносим числа в текст без проверки кодом или первоисточником.
