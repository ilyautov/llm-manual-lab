# Настоящий токенизатор

PDF объясняет одно слияние BPE на маленьком искусственном корпусе. Этот опыт показывает реальные ID кодировки `cl100k_base` и байты токенов. Он не воспроизводит токенизатор локальной модели Ollama: у неё может быть другая кодировка.

```bash
python3 -m pip install tiktoken==0.14.0
python3 scripts/inspect_tokens.py
python3 scripts/inspect_tokens.py 'аромадиффузор'
```

Проверка: `round_trip_exact` должна быть `true`. Отдельный токен может содержать только часть UTF-8 символа, поэтому поле `utf8_piece` иногда показывает знак замены. Для точного просмотра используйте `bytes_hex`; декодирование всей последовательности возвращает исходную строку.

Сравнение одной русской и одной английской фразы показывает только эти две строки в этой кодировке. По ним нельзя делать общий вывод о стоимости языков, моделей или задач. Для собственного бюджета запускайте скрипт на настоящих инструкциях, документах и ожидаемых ответах и используйте кодировку именно выбранной модели.
