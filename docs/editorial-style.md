# Редакторские правила мануала

Цель — сохранять строгую механику и не заставлять читателя угадывать значение нового слова.

| Понятие | Основное написание | Как вводить |
| --- | --- | --- |
| Loss | функция потерь (loss) | «Штраф» допустим только как пояснение числового примера; «ошибка» не заменяет название функции. |
| FFN | полносвязная сеть FFN | При первом появлении раскрыть feed-forward network и её роль в блоке трансформера. |
| Distillation | дистилляция | Английское слово оставить в скобках при первом упоминании и в словаре. |
| Trace | трасса исполнения | `trace_id` и имена полей кода сохранять буквально. |
| Runtime | программа исполнения (runtime) | При первом появлении сказать, что она проверяет права и выполняет вызов. |
| SFT / LoRA | SFT — цель обучения на эталонных ответах; LoRA — способ выбирать обучаемые параметры | Не писать, что SFT обязательно обновляет всю базу или что LoRA обновляет базовые веса. |

Десятичные дроби набираются с запятой; координаты вектора разделяются точкой с запятой: `(1; 0)`. Ссылку ставим рядом с утверждением, которое поддерживает первоисточник. Ограничение примера объясняем один раз при введении или там, где без него читатель сделает неверный вывод; общую оговорку не повторяем после каждой таблицы.
