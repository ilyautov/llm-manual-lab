# От формулы к строке кода

| В PDF | В проекте | Как читать |
| --- | --- | --- |
| `pᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)` | `softmax(logits)` | Положительный вес одного токена делится на сумму весов всех токенов |
| `L = −ln p(цель)` | `crossEntropy(probabilities, targetId)` | Чем ниже вероятность нужного токена, тем выше штраф |
| `∂L/∂zᵢ = pᵢ − 1[i=цель]` | `gradient` в `trainSentence()` | Для правильного токена вычитается единица; для остальных остаётся их вероятность |
| `z' = z − η∇L` | `logitsAfter` | Один шаг меняет только выбранную строку параметров |
| `x=z(я)−z(чай)`, `y=z(люблю)−z(чай)` | разности в `logitsBefore` и `logitsAfter` | Координаты 3D-поверхности и карты сверху; общий сдвиг logits исключён |
| `L(x,y)=ln(1+exp(x)+exp(y))` | `lossOnSurface(x,y)` и `crossEntropy(softmax(logits), 2)` | Высота той же поверхности для цели «чай» |
| `softmax(mask(QKᵀ/√dₖ))V` | `attentionRow()` в `src/tiny-attention.ts` | Одна вычисляемая голова causal attention с фиксированными Q, K и V |

Вычисление `softmax` вычитает максимальный logit перед `exp` для численной устойчивости. Это не меняет вероятностей: общий множитель в числителе и знаменателе сокращается.

Здесь `z` — непосредственно обучаемая строка таблицы. В трансформере logits получают после многих слоёв и обучения гораздо большего набора параметров. Схема шага `softmax → loss → gradient → update` остаётся той же идеей, но вычисление градиентов внутри большой модели сложнее.
