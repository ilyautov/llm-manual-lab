# Рабочие бланки к мануалу

Скопируйте нужный файл и заполняйте на собственном случае. Поля специально отделяют ожидаемое поведение от наблюдаемого результата. Пустое поле означает «не проверено», а не «успех».

| Бланк | Когда использовать | Раздел книги |
| --- | --- | --- |
| [Трасса случая](trace.md) | Разобрать один ответ или действие по источникам и журналу исполнения | стр. 60, 64 |
| [ТЗ на дообучение](fine-tuning-brief.md) | Решить, нужны ли новые веса, и задать данные и критерии | стр. 26, 28–33 |
| [Сравнение версий](version-comparison.md) | Проверить A и B на одинаковых случаях до переключения | стр. 56–59 |
| [Оценка свободного ответа](free-answer-rubric.md) | Проверить факт, действие и ограничения без точного совпадения фраз | стр. 59 |
| [Сессия с читателем](reader-session.md) | Записать реальные затруднения при чтении книги | [протокол пилота](../docs/reader-pilot.md) |

Не помещайте в бланки секреты и лишние персональные данные. Для спорного вывода сохраняйте ссылку на исходную трассу или документ, доступный вашей команде. Учебные примеры в книге не являются результатами вашего проекта.
