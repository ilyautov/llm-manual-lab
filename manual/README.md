# Исходники PDF

`source.docx` содержит исходные 24 главы. `editorial_content.py` хранит точечные редакторские поправки и практикум; `build_pdf.py` собирает базовую книгу; `build_manual.py` ставит технические атласы после соответствующих глав и добавляет новые разборы, вопросы, живую лабораторию и приложение с ответами. Четыре изображения в `assets/` используются как художественные иллюстрации (JPEG). Технические графики строятся кодом. Технические графики строятся кодом, без готовых растров. Шрифты сборки лежат в `fonts/` (Noto Sans, Noto Serif, Liberation Mono: SIL OFL 1.1; DejaVu: свободная лицензия Bitstream), поэтому PDF собирается из чистого клона.

## Редакционные правила

Сводка обязательных написаний терминов книги: [docs/editorial-style.md](../docs/editorial-style.md).

## Сборка

Из корня репозитория:

```bash
python3 -m pip install -r manual/requirements.txt
python3 manual/build_manual.py
python3 scripts/check_pdf.py
```

Результат: `manual/out/Теория_LLM_полный_мануал.pdf`. Сборка не обращается к сети. Предварительный проход получает номера глав, второй уточняет колонтитулы после добавления страниц в словарь, третий сохраняет итоговый PDF. После сборки удаляются пустые служебные команды Helvetica; видимый текст ими не набирается. Девять формул набираются векторным компоновщиком `math_typesetting.py`, который проверяет наличие каждого символа в шрифте до записи PDF. Нужны шрифты `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf`, `NotoSerif-Regular.ttf`, `NotoSerif-Italic.ttf`, `LiberationMono-Regular.ttf`, `DejaVuSans.ttf` и `DejaVuMathTeXGyre.ttf`. На исходном хосте они берутся из комплекта Codex/LibreOffice. На другом хосте задайте папку с этими свободными шрифтами:

```bash
LLM_MANUAL_FONTROOT=/path/to/font-directory \
python3 manual/build_manual.py
```

Выходные сведения берутся из `manual/publication.json`. Если поле `author` пустое, выходная страница не добавляется и метаданные Author остаются пустыми. Если автор указан, сборка добавляет страницу в конце и записывает то же имя в метаданные PDF. Контакт и условия распространения заданы автором. Текст и оригинальные иллюстрации книги лицензированы по CC BY-NC 4.0; код лаборатории — по MIT. Подробности и границы лицензий находятся в `LICENSE-BOOK.md` и `LICENSE-CODE.txt` в корне архива.

Ожидаемый результат текущей редакции — 82 страницы A4, включая выходную страницу. Проверка `scripts/check_pdf.py` сверяет готовый PDF: запрещённые опечатки, все 78 ссылок словаря, 43 точных якоря объяснений, символы девяти формул, наличие расчётных задач, автора в метаданных и отсутствие невстроенных шрифтов в ресурсах страниц. [Редакторская сверка](../docs/glossary-audit.md) описывает 25 перенесённых ссылок и основания для остальных. Язык PDF указан как `ru-RU`. Генератор не создаёт структурные теги PDF/UA; текст выделяется и извлекается, но для полноценной доступности потребуется отдельная редакционная сборка. В [истории редакций](../CHANGELOG.md) указаны изменения. Контакт и условия распространения показаны на выходной странице.
